# Review Checklist

Antes de aceptar cambios:

- [ ] No se añadió backend.
- [ ] No se añadió Supabase.
- [ ] No se añadió autenticación.
- [ ] No se añadieron dependencias innecesarias.
- [ ] No se almacenan videos.
- [ ] Export/import JSON funciona.
- [ ] Dashboard grupal fusiona por `student_code`.
- [ ] Se respeta `progress.last_updated`.
- [ ] Portafolio emergente se actualiza.
- [ ] Avisos de privacidad visibles.
- [ ] README actualizado si aplica.
- [ ] CHANGELOG actualizado si aplica.
- [ ] Bitácora creada o actualizada.
