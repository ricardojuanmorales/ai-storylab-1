# Prompt de Revisión de Arquitectura

Actúa como revisor de arquitectura del MVP AI StoryLab.

Evalúa:
1. alcance local-first;
2. ausencia de backend;
3. ausencia de Supabase;
4. separación de componentes;
5. claridad de JSON;
6. localStorage centralizado;
7. export/import;
8. portafolio emergente;
9. dashboard grupal;
10. estación de entrega final.

No hagas cambios. Entrega informe con fortalezas, riesgos y recomendaciones.
