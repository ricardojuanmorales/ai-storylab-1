# Matriz PH-IT-AT · Entrada H08-3

| Rol | Pregunta | Criterio |
|---|---|---|
| PH | ¿se conserva agencia? | ningún borrado o migración irreversible automática |
| PH | ¿se conserva privacidad? | índice sin contenido sensible |
| PH | ¿se explica el fallo? | mensajes seguros y acciones claras |
| IT | ¿es migrable? | pipeline explícito, determinista y probado |
| IT | ¿es recuperable? | staging y fault injection |
| IT | ¿es reemplazable? | puerto independiente del storage |
| IT | ¿es observable sin telemetría? | estado local tipado, sin red |
| AT | ¿se conserva el proceso creativo? | M1 intacta después de migrar |
| AT | ¿se evita castigar el error? | recuperación y lenguaje no punitivo |
