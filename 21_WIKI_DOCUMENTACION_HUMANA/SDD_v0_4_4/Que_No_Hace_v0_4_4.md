# Qué no hace AI StoryLab 1 v0.4.4

**Estado:** Borrador inicial para Wiki humana  
**Ruta sugerida:** `21_WIKI_DOCUMENTACION_HUMANA/SDD_v0_4_4/Que_No_Hace_v0_4_4.md`

---

En v0.4.4, AI StoryLab 1 no está autorizado a:

```text
crear backend;
usar cloud;
usar APIs externas;
crear autenticación;
crear analíticas;
usar base de datos remota;
subir archivos automáticamente;
publicar automáticamente;
usar IA externa por defecto;
manejar datos reales;
evaluar automáticamente como juez final;
implementar funcionalidad.
```

Esto no significa que el proyecto esté detenido. Significa que está preparando reglas de cuidado antes de construir.

La fase actual sirve para diseñar specs, políticas, matrices y guías.
