# Problemas conocidos y limitaciones · AI StoryLab 1 v1.0.0

- Windows no forma parte del soporte validado actual.
- `file://` no está soportado.
- No se afirma soporte universal de navegadores.
- No existe certificación WCAG.
- No hay backend, cuenta, sincronización ni recuperación remota.
- Borrar almacenamiento del navegador puede eliminar proyectos.
- La IA es externa y guiada, no embebida.
- No se afirma efectividad educativa poblacional.
- No existe firma criptográfica ni provenance SLSA.

Vista de facilitador, dashboard grupal, IA embebida, colaboración sincrónica, telemetría, galería pública y datos reales están fuera de v1.0.0.
