# Orientaciones para docentes e investigadores · AI StoryLab 1 v1.0.0

## Docentes
Define propósito educativo, utiliza datos sintéticos o autorizados, evita vigilancia, evalúa proceso y decisiones, y adapta el lenguaje sin alterar privacidad. La interfaz especializada de facilitador está diferida.

## Investigadores
La versión ofrece trazabilidad local, exportación y modelos de evidencia, pero no autoriza investigación con personas ni datos reales. Todo estudio requiere protocolo, consentimiento, revisión ética, minimización de datos y gate independiente.
