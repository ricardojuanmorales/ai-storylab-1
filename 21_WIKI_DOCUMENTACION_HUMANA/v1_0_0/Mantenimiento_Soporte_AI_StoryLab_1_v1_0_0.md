# Mantenimiento y soporte · AI StoryLab 1 v1.0.0

## Reportar un problema
Incluye versión o commit, navegador, sistema operativo, pasos, resultado esperado, resultado observado y mensajes de error. No incluyas datos privados.

## Severidad
- Crítica: pérdida generalizada de datos, ejecución de contenido no confiable o publicación accidental.
- Alta: flujo M1-M4, exportación o recuperación bloqueados.
- Media: degradación importante con alternativa.
- Baja: documentación o detalle visual.

Cada corrección debe conservar trazabilidad, pruebas, documentación y revisión proporcional al riesgo.
