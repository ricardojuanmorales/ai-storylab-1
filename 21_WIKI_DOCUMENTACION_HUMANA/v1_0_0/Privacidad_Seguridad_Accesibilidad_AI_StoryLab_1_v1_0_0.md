# Privacidad, seguridad y accesibilidad · AI StoryLab 1 v1.0.0

El flujo principal no requiere cuenta, backend, nube, telemetría ni APIs de IA. Los proyectos se conservan en el navegador.

- usa datos propios, autorizados o sintéticos;
- no introduzcas secretos;
- verifica hashes de releases;
- reporta vulnerabilidades sin detalles explotables públicos.

La interfaz incluye estructura semántica, teclado, salto al contenido y preferencias visuales. No se afirma certificación WCAG, soporte universal de lectores de pantalla ni compatibilidad con todos los navegadores.

## Hosting en GitHub Pages
GitHub Pages servirá archivos estáticos cuando se autorice. AI StoryLab 1 no
añade backend, cuentas, telemetría propia ni sincronización.
