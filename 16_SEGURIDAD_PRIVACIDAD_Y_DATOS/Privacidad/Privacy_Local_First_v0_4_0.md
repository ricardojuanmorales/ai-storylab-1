# PRIVACY_LOCAL_FIRST.md

## Principio

El MVP guarda progreso localmente en el navegador mediante `localStorage`. No sube datos a una base de datos.

## Reglas

- No recopilar datos personales innecesarios.
- Usar códigos o seudónimos.
- No subir JSON reales de estudiantes al repositorio público.
- No subir videos estudiantiles no validados.
- No publicar enlaces privados.
- No guardar archivos grandes en `localStorage`.
- El video final se entrega en un espacio administrado por el facilitador.

## Aviso para estudiantes

Este MVP guarda progreso localmente en este navegador. Exporta tu JSON para respaldo y entrégalo solo al facilitador si se solicita.
