# Contributing

## Reglas de contribución

1. Trabajar en ramas.
2. No subir datos reales.
3. Documentar cambios.
4. Probar antes de commit.
5. Mantener alcance MVP.
6. No introducir backend sin decisión documentada.
7. Usar mensajes de commit claros.

## Convención de commits

- `feat:` nueva funcionalidad
- `fix:` corrección
- `docs:` documentación
- `chore:` tarea auxiliar
- `refactor:` reorganización
- `data:` cambios en JSON
- `governance:` gobernanza
