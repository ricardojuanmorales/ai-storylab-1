# Release Criteria

## MVP listo cuando

- [ ] Permite crear perfil local.
- [ ] Permite navegar nueve misiones.
- [ ] Permite completar misiones.
- [ ] Otorga badges.
- [ ] Construye portafolio emergente.
- [ ] Guarda en localStorage.
- [ ] Exporta progreso JSON.
- [ ] Importa progreso JSON.
- [ ] Dashboard grupal importa múltiples JSON.
- [ ] Fusiona por `student_code`.
- [ ] Registra metadatos de video final.
- [ ] No almacena videos.
- [ ] Incluye avisos de privacidad.
- [ ] Funciona sin backend.
