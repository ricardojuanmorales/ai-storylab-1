# Decisión : Aprobación de SPEC-OP-006 Consentimiento Informado y Situado

**Proyecto:** AI StoryLab 1  
**Fase:** v0.4.5, specs operativas con semillas arquitectónicas  
**Fecha:** 2026-07-04  
**PR:** #11  
**Estado:** aprobada para Specs Núcleo con deuda controlada

> **Guardarraíl constitucional v0.4.5**  
> Esta decisión no autoriza implementación funcional, backend, cloud, autenticación, analíticas, IA externa, manejo de datos reales, subida automática ni automatizaciones funcionales.

## 1. Decisión

Se aprueba **SPEC-OP-006 Consentimiento Informado y Situado** como primera esclusa operativa de Specs Núcleo v0.4.5 bajo el estado:

```text
aprobada_para_specs_nucleo_con_deuda_controlada
```

## 2. Alcance de la aprobación

La aprobación autoriza usar SPEC-OP-006 como criterio rector para revisar specs posteriores que toquen datos, evidencia, reflexión, portafolio, exportación, compartir, investigación, evaluación, IA futura, seguridad local-first y experiencia de estudiantes de escuela superior.

## 3. Lo que no autoriza

```text
[!] Implementación funcional.
[!] UI real.
[!] Backend, cloud, autenticación o analíticas.
[!] Uso de datos reales.
[!] Exportaciones reales.
[!] Automatizaciones funcionales.
[!] IA externa.
[!] Pruebas con personas.
[!] Consentimiento legal formal.
```

## 5. Deuda controlada

```text
DEUDA-SESION-001: actualizar glosario general SDD con términos de consentimiento.
DEUDA-SESION-002: identificar documentos necesarios para la base de conocimiento SDD del PH.
DEUDA-SESION-003: desarrollar criterios de transición entre capas de consentimiento.
DEUDA-SESION-004: consolidar criterios de consentimiento para estudiantes de escuela superior.
DEUDA-SESION-005: crear regla triangular común para Specs Núcleo.
DEUDA-PH-001: guía PH para consentimiento, mediación, coerción y fatiga.
DEUDA-PH-002: guía PH para consentimiento y agencia estudiantil en contextos escolares.
DEUDA-PH-003: checklist PH para acciones sensibles.
```

## 6. Dictamen PH-IT-AT

```text
PH:
  La spec protege agencia humana, no coerción, comprensión, cuidado reforzado de menores
  y límites frente a presión académica o evaluación automática.

IT:
  La spec establece trazabilidad documental para acciones sensibles y dependencia explícita
  con datos, privacidad y seguridad local-first.

AT:
  La spec protege la experiencia creativa al evitar formularización excesiva,
  fatiga de consentimiento y bloqueo prematuro de la exploración.
```

## 7. Continuidad

La siguiente spec a revisar será **SPEC-OP-007 : Datos y Privacidad**. SPEC-OP-007 deberá heredar la regla triangular y declarar explícitamente su relación con consentimiento informado y situado.
