# Decisión : Aprobación de SPEC-OP-008 Seguridad Local-First

**Proyecto:** AI StoryLab 1  
**Fase:** v0.4.5, specs operativas con semillas arquitectónicas  
**Fecha:** 2026-07-04  
**PR:** #11  
**Estado:** aprobada para Specs Núcleo con deuda controlada

> **Guardarraíl constitucional v0.4.5**  
> Esta decisión no autoriza implementación funcional, backend, cloud, autenticación, analíticas, IA externa, manejo de datos reales, subida automática ni automatizaciones funcionales.

## 1. Decisión

Se aprueba **SPEC-OP-008 Seguridad Local-First** como tercera esclusa operativa de Specs Núcleo v0.4.5 bajo el estado:

```text
aprobada_para_specs_nucleo_con_deuda_controlada
```

## 2. Alcance de la aprobación

La aprobación autoriza usar SPEC-OP-008 como criterio rector para revisar specs posteriores que toquen experiencia creativa local-first, guardado local, evidencia, portafolio, exportación, compartir, contexto escolar, dispositivo compartido, investigación, evaluación, IA futura, amenaza conceptual, arquitectura conceptual, controles humanos y seguridad habitable.

## 3. Lo que no autoriza

```text
[!] Implementación funcional.
[!] UI real.
[!] Backend, cloud, autenticación o analíticas.
[!] Uso de datos reales.
[!] Captura, almacenamiento, cifrado, permisos o retención técnica.
[!] Sincronización o respaldo real.
[!] Exportaciones reales.
[!] Automatizaciones funcionales.
[!] IA externa.
[!] Pruebas con personas.
[!] Resolver threat model técnico.
[!] Garantizar seguridad real.
```

## 6. Dictamen PH-IT-AT

```text
PH:
  La spec protege confianza situada, agencia humana, no coerción,
  comprensión de riesgos, protección de estudiantes y cuidado frente
  a contextos escolares o dispositivos compartidos.

IT:
  La spec establece zonas de seguridad conceptual, threat model documental,
  escalamiento de amenazas, controles humanos, relación con datos y límites
  antes de arquitectura técnica.

AT:
  La spec protege la experiencia creativa al exigir seguridad proporcional,
  avisos habitables, pausas, cancelación y no castigo a la exploración.
```

## 7. Dictamen

SPEC-OP-008 queda aprobada como tercera esclusa operativa de Specs Núcleo v0.4.5. Su aprobación cierra la tríada inicial de protección:

```text
SPEC-OP-006: consentimiento informado y situado.
SPEC-OP-007: datos, privacidad y minimización.
SPEC-OP-008: seguridad local-first y amenaza conceptual.
```

La tríada queda habilitada como criterio rector para futuras specs, sin autorizar implementación funcional.
