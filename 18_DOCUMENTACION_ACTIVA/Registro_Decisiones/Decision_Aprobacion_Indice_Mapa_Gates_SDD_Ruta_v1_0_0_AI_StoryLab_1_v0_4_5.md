# Decisión : Aprobación del Índice Oficial y Mapa de Gates SDD hacia v1.0.0

**Proyecto:** AI StoryLab 1  
**Fecha:** 2026-07-04  
**Versión:** v0.4.5  
**PR:** #11, `docs: apertura operativa v0.4.5 specs núcleo`  
**Estado:** decisión aprobada para commit de hito  
**Documentos aprobados:**
- `Indice_Oficial_Gates_SDD_Ruta_v1_0_0_AI_StoryLab_1_v0_4_5.md`
- `Mapa_Gates_SDD_Ruta_v1_0_0_AI_StoryLab_1_v0_4_5.md`
- `Tablero_Maestro_Dependencias_Specs_Gates_Versiones_AI_StoryLab_1_v0_4_5.md`

> **Guardarraíl constitucional v0.4.5**  
> Esta decisión no autoriza implementación funcional, código, backend, cloud, autenticación, analíticas, IA externa por defecto, datos reales, subida automática ni automatizaciones funcionales. Autoriza únicamente la incorporación documental del índice, mapa y documentos relativos como hito de PR #11.

## 1. Decisión

Se aprueba el `Mapa_Gates_SDD_Ruta_v1_0_0_AI_StoryLab_1_v0_4_5.md` como desarrollo estratégico-operativo del `Indice_Oficial_Gates_SDD_Ruta_v1_0_0_AI_StoryLab_1_v0_4_5.md`.

El Índice Oficial de Gates debe incluirse en el mismo commit que el mapa para que ambos documentos formen una unidad canónica:

```text
indice = estructura estable de gates
mapa = desarrollo longitudinal de la estructura
```

## 2. Razón

El índice y el mapa funcionan como par documental. Separarlos en commits distintos debilitaría la trazabilidad del hito. Juntos establecen la ruta de gobierno SDD hacia v1.0.0: versiones, gates, specs requeridas, evidencia, deuda, revisión PH-IT-AT y bloqueos constitucionales.

## 3. Alcance aprobado

```text
incluye:
  - Índice Oficial de Gates SDD hacia v1.0.0;
  - Mapa de Gates SDD hacia v1.0.0;
  - Tablero Maestro de Dependencias Specs-Gates-Versiones;
  - decisión documental de aprobación;
  - tabla de ubicación canónica;
  - bitácoras activas actualizadas;
  - transferencia simétrica activa actualizada;
  - changelog actualizado;
  - registro de deuda del hito;
  - Bitácora del Capitán actualizada;
  - prompt de continuidad post-mapa.

excluye:
  - implementación funcional;
  - arquitectura detallada operativa;
  - diseño de UI funcional;
  - prototipos ejecutables;
  - pruebas con datos reales;
  - activación de IA externa;
  - exportación real;
  - automatización.
```

## 4. Criterio de aprobación aplicado

```text
[✓] El mapa conserva el orden A+B+C+D.
[✓] El mapa usa el índice como esqueleto estable.
[✓] El mapa declara qué autoriza y qué bloquea cada gate.
[✓] El mapa define evidencia, deuda y revisión PH-IT-AT por transición.
[✓] El mapa preserva local-first y consentimiento situado.
[✓] El mapa no autoriza implementación.
[✓] El índice queda incluido en el mismo commit que el mapa.
```

## 5. Impacto PH-IT-AT

```text
PH: fortalece agencia humana, consentimiento, cuidado de perfiles y bloqueo de automatismos opacos.
IT: organiza trazabilidad, evidencia, investigación-creación y criterios de validez por gate.
AT: preserva experiencia creativa no rígida, lenguaje habitable y dimensión afectiva del proceso.
```

## 6. Dictamen

El Índice Oficial y el Mapa de Gates SDD hacia v1.0.0 quedan aprobados como hito documental de PR #11. El proyecto cuenta ahora con una brújula doble: una estructura de compuertas y una carta de navegación longitudinal.

La próxima etapa podrá volver a la revisión unitaria de Specs Núcleo, comenzando por el cierre condicionado de SPEC-OP-006, sin perder la ruta global hacia v1.0.0.
