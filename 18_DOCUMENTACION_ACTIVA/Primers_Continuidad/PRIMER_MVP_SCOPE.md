# Primer — Alcance MVP

## Incluye

- Perfil local.
- Nueve misiones.
- Formularios por sesión.
- Badges.
- Portafolio emergente.
- Dashboard individual.
- Dashboard grupal local.
- Export/import JSON.
- Estación de entrega final por metadatos.

## No incluye

- Backend.
- Supabase.
- Login.
- Subida de archivos.
- Almacenamiento de videos.
- Galería dinámica.
- APIs externas.
