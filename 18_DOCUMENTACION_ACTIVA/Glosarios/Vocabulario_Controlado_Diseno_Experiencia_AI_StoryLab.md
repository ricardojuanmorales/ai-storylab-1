## 1. Propósito

Este documento paga la deuda residual identificada como:

```text
DEUDA-V047-003
vocabulario_controlado_arquitectura_conceptual
```

Su propósito es fijar un vocabulario común para evitar que términos conceptuales de v0.4.7 se confundan con implementación, diseño funcional, investigación, evaluación o captura de datos reales.

El vocabulario funciona como baranda documental: no impide caminar, pero evita caer en cubierta técnica antes de tiempo.

---

## 2. Guardarraíl

Este documento no define:

```text
[!] componentes de UI;
[!] permisos técnicos;
[!] eventos;
[!] endpoints;
[!] modelos de datos;
[!] arquitectura;

[!] instrumentos de evaluación;
[!] actividades con personas reales.
```

## 4. Términos controlados principales

### 4.1 Acción sensible

```text
definicion:
  Unidad conceptual de revisión que puede afectar consentimiento, privacidad, visibilidad, evidencia, interpretación o seguridad local-first.

uso_permitido:
  Revisar riesgos documentales antes de cualquier fase futura.

evitar_confundir_con:
  función del sistema
  evento técnico
  permiso
  endpoint
  botón
  automatización

alerta:
  Si una acción sensible empieza a escribirse como tarea técnica, debe escalar al gate.
```

---

### 4.2 Agencia humana

```text
definicion:
  Capacidad de la persona para entender, decidir, pausar, retirar, revisar, disputar interpretaciones y conservar control sobre su proceso creativo.

uso_permitido:
  Criterio rector de lenguaje, escenarios, portafolio conceptual y controles habitables.

evitar_confundir_con:
  preferencia de usuario
  configuración
  autorización técnica

alerta:
  La agencia no puede depender de una opción escondida o de una aceptación obligatoria.
```

---

### 4.3 Consentimiento situado

```text
definicion:
  Comprensión contextual y revisable de una invitación o acción, con posibilidad real de pausa y retiro.

uso_permitido:
  Pregunta documental para revisar escenarios y acciones sensibles.

evitar_confundir_con:
  consentimiento legal
  consentimiento investigativo
  aceptación de términos
  checkbox

alerta:
  En v0.4.7 no se autoriza consentimiento investigativo ni legal operativo.
```

---

### 4.4 Pausa

```text
definicion:
  Derecho conceptual a detener el proceso sin penalidad, explicación obligatoria ni pérdida de legitimidad.

uso_permitido:
  Control habitable y criterio de interfaz no rígida.

evitar_confundir_con:
  suspender sesión
  guardar estado
  detener ejecución

alerta:
  La pausa no debe transformarse en métrica de desempeño.
```

---

### 4.5 Retiro

```text
definicion:
  Derecho conceptual a sacar una pieza, reflexión, escenario o evidencia ficticia de una zona de visibilidad o revisión.

uso_permitido:
  Criterio de agencia y reversibilidad.

evitar_confundir_con:
  borrar archivo
  eliminar registro
  revocar permiso técnico

alerta:
  En v0.4.7 no se define mecanismo técnico de borrado o retención.
```

---

### 4.6 Evidencia ficticia

```text
definicion:
  Pieza inventada o ejemplo documental usado para pensar cómo podría nombrarse una evidencia sin recoger datos reales.

uso_permitido:
  Escenarios ficticios, microcopy revisable y matrices conceptuales.

evitar_confundir_con:
  evidencia real
  entrega de estudiante
  dato de investigación
  archivo almacenado

alerta:
  Toda evidencia ficticia debe estar marcada como inventada y no aplicable.
```

---

### 4.7 Evidencia real

```text
definicion:
  Material producido por una persona real en un contexto real.

uso_permitido:
  Solo como límite o deuda futura no activada.

evitar_confundir_con:
  evidencia ficticia
  ejemplo documental
  escenario inventado

alerta:
  v0.4.7 no autoriza captura, almacenamiento, análisis, exportación ni uso de evidencia real.
```

---

### 4.8 Portafolio conceptual

```text
definicion:
  Construcción documental imaginada para pensar selección, visibilidad y revisión de piezas creativas sin crear un portafolio funcional.

uso_permitido:
  Revisar criterios de agencia, selección, pausa y retiro.

evitar_confundir_con:
  portafolio real
  expediente
  repositorio
  almacenamiento
  perfil de usuario

alerta:
  No debe convertirse en estructura de datos ni producto.
```

---

### 4.9 Expediente

```text
definicion:
  Registro totalizante o acumulativo sobre una persona.

uso_permitido:
  Término de alerta para evitar que el portafolio conceptual se convierta en vigilancia.

evitar_confundir_con:
  portafolio conceptual
  selección creativa
  curaduría voluntaria

alerta:
  Toda tendencia a expediente debe bloquearse en v0.4.7.
```

---

### 4.10 Interfaz conceptual

```text
definicion:
  Relación habitable imaginada entre persona, lenguaje, acción sensible y control humano.

uso_permitido:
  Criterios de interfaz no rígida y mapas de experiencia.

evitar_confundir_con:
  UI real
  pantalla
  wireframe
  prototipo
  navegación

alerta:
  Si se puede dibujar como pantalla funcional, probablemente cruzó el guardarraíl.
```

---

### 4.11 UI real

```text
definicion:
  Diseño visual o interactivo de una interfaz aplicable o construible.

uso_permitido:
  Solo como límite no autorizado en v0.4.7.

evitar_confundir_con:
  interfaz conceptual

alerta:
  UI real está fuera de alcance.
```

---

### 4.12 Control habitable

```text
definicion:
  Capacidad conceptual de cuidado que permite a una persona pausar, retirar, revisar, disputar, limitar visibilidad o pedir revisión humana.

uso_permitido:
  Describir condiciones humanas de habitabilidad.

evitar_confundir_con:
  permiso técnico
  configuración
  botón
  regla de sistema

alerta:
  No convertir controles habitables en funciones.
```

---

### 4.13 Permiso técnico

```text
definicion:
  Mecanismo operativo de autorización en un sistema.

uso_permitido:
  Solo como contraste o deuda futura bloqueada.

evitar_confundir_con:
  control habitable
  consentimiento situado

alerta:
  v0.4.7 no diseña permisos técnicos.
```

---

### 4.14 Escenario ficticio

```text
definicion:
  Situación inventada, no identificable y no aplicable directamente, usada para pensar riesgos de experiencia.

uso_permitido:
  Revisar edad, perfil, contexto y acción sensible.

evitar_confundir_con:
  caso real
  actividad de clase
  prueba piloto
  test de usuario

alerta:
  Un escenario ficticio no debe ejecutarse con personas.
```

---

### 4.15 Actividad real

```text
definicion:
  Acción aplicada con personas reales en un contexto real.

uso_permitido:
  Solo como límite no autorizado.

evitar_confundir_con:
  escenario ficticio

alerta:
  v0.4.7 no autoriza actividades reales.
```

---

### 4.16 Microcopy ficticia

```text
definicion:
  Frase inventada y revisable usada para estudiar tono, claridad y riesgo.

uso_permitido:
  Guía de lenguaje y escenarios ficticios.

evitar_confundir_con:
  copy final
  onboarding
  mensaje de producto

  No debe copiarse como texto final de una interfaz.
```

---

### 4.17 Zona conceptual

```text
definicion:
  Región documental de experiencia, como invitación, exploración, revisión, visibilidad o salida.

uso_permitido:
  Mapa de experiencia y matriz de acciones sensibles.

evitar_confundir_con:
  pantalla
  módulo
  ruta
  flujo de navegación

alerta:
  Zona conceptual no equivale a arquitectura de información funcional.
```

---

### 4.18 Investigación implícita

```text
definicion:
  Riesgo de tratar reflexiones, escenarios o patrones ficticios como datos o hallazgos de investigación.

uso_permitido:
  Alerta y deuda bloqueada.

evitar_confundir_con:
  reflexión documental
  revisión conceptual

alerta:
  Debe bloquearse hasta fase futura explícitamente autorizada, si alguna vez aplica.
```

---

### 4.19 Gate documental

```text
definicion:
  Punto de revisión que decide si la fase puede cerrar, continuar, transferir deuda o bloquear transición.

uso_permitido:
  Evaluar condiciones documentales sin autorizar implementación.

evitar_confundir_con:
  lanzamiento
  aprobación de prototipo
  inicio de desarrollo

alerta:
  El gate puede preparar condiciones, no abrir construcción.
```

---

### 4.20 Pago documental de deuda

```text
definicion:
  Resolución de una deuda mediante documentación SDD no funcional aprobada.

uso_permitido:
  Cerrar deuda conceptual, lingüística, ética o de revisión.

evitar_confundir_con:
  implementación
  validación empírica
  prueba funcional

alerta:
  Una deuda técnica o investigativa no puede pagarse en v0.4.7.
```

## 5. Pares que no deben confundirse

| Término permitido | No confundir con |
|---|---|
| evidencia ficticia | evidencia real |
| escenario ficticio | actividad real |
| interfaz conceptual | UI real |
| control habitable | permiso técnico |
| acción sensible | función del sistema |
| zona conceptual | pantalla |
| microcopy ficticia | copy final |
| portafolio conceptual | expediente |
| revisión documental | evaluación automática |
| gate documental | autorización de prototipo |
