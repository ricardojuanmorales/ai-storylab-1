## 1. Propósito

Este plan ordena la ruta hacia una v1.0.0 publicable como ecosistema completo.

La referencia a GitHub Marketplace se entiende como meta de preparación publicable, distribución, documentación, release readiness y gobernanza de mantenimiento. La forma exacta de publicación deberá verificarse técnicamente en fases posteriores.
