## Idea central

El camino hacia v1.0.0 no es:

```text
documentar → diseñar pantalla → programar → lanzar
```

Es:

```text
documentar → revisar → cerrar deuda → pasar gate → decidir si se avanza
```

---

## Ruta simple

```text
v0.4.5:
  pregunta: ¿Cuáles son las reglas profundas?
  respuesta: consentimiento, privacidad, seguridad local-first y agencia humana.

v0.4.6:
  pregunta: ¿Cómo se organiza conceptualmente el sistema?
  respuesta: arquitectura conceptual no funcional.

v0.4.7:
  pregunta: ¿Cómo se imagina la experiencia humana sin construirla?
  respuesta: lenguaje situado, escenarios ficticios, controles habitables y gate.

v0.4.8:
  pregunta: ¿Qué quedó cerrado después del merge y qué falta ordenar?
  respuesta: cierre post-merge, consolidación e índices.

v0.4.9:
  pregunta: ¿Estamos listos para considerar una fase mayor?
  respuesta: gobernanza de transición.

v0.5.x:
  pregunta: ¿Se puede evaluar una transición sin romper reglas?
  respuesta: evaluación documental condicionada.

v0.6.x:
  pregunta: ¿Se puede empezar a pensar diseño funcional?
  respuesta: solo si gates futuros lo autorizan.

v0.7.x:
  pregunta: ¿Se puede pensar arquitectura técnica?
  respuesta: solo si se autoriza y se gobierna explícitamente.

v0.8.x:
  pregunta: ¿Se puede pensar prototipo controlado?
  respuesta: solo si gates previos lo permiten.

v0.9.x:
  pregunta: ¿Está todo listo como candidato a versión estable?
  respuesta: release candidate documental.

v1.0.0:
  pregunta: ¿El sistema está estable, trazable y gobernado?
  respuesta: versión estable documentalmente gobernada.
```

---

## Frase corta

```text
Primero cartas, brújula, reglas de navegación y puertos seguros.
Después, solo si procede, motores.
```

---

## Qué significa v1.0.0

v1.0.0 no significa necesariamente "app funcionando".

Significa:

```text
sistema_documentalmente_estable
gobernanza_por_gates
trazabilidad
agencia_humana
seguridad_local_first
no_extractivismo
deuda_controlada
```

---

## Cierre

El mapa de ruta hacia v1.0.0 es una serie de esclusas. Cada compuerta abre solo si el agua documental está nivelada.
