# V10-5 · Versión, schema y artefacto

Este cartapacio contiene el contrato de identidad de candidata, la política de
versionado, la independencia del schema, una sonda local de reproducibilidad,
checksums y una atestación interna.

El ZIP de la sonda permanece fuera del repositorio, en el estado reanudable del
operador. No es una RC, no es la candidata final y no está publicado.
