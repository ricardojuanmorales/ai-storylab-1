# V10-4 · Seguridad, privacidad y cadena de suministro

Este cartapacio contiene:

- informe ejecutivo;
- matriz de hallazgos;
- matriz de vulnerabilidades NPM;
- inventario de dependencias y licencias;
- controles de CI y referencias de acciones;
- resultados normalizados;
- estado canónico, manifiesto y checksums.

La evidencia cruda permanece en el directorio externo reanudable del operador y
se enlaza mediante hashes SHA-256. No se ejecutaron reparaciones, cambios de
dependencias ni cambios de workflows.
