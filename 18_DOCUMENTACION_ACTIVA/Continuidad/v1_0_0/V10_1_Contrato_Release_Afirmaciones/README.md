# V10-1 · Contrato de release y disciplina de afirmaciones

Este cartapacio define:

- el significado gobernado de `v1.0.0`;
- el descriptor permitido antes de la publicación;
- afirmaciones verificadas, acotadas, no afirmadas y prohibidas;
- soporte actualmente demostrado y soporte pendiente;
- criterios que bloquearían una publicación;
- límites de autoridad y continuidad hacia V10-2.

No contiene pruebas nuevas de compatibilidad ni cambios funcionales. V10-2
permanece bloqueado hasta decisión humana.
