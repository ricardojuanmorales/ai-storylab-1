## 2. Decisión estratégica

La apertura de v0.8.0 no será un salto desde documentación hacia código
indiferenciado. Será una transición gobernada desde SDD hacia incrementos
pequeños, reversibles, probados y trazables.

## 3. Modelo humano, máquina e IA

```text
persona:
  decide sentido, alcance, riesgo y gates

máquina:
  verifica Git, tests, hashes, schemas y estados reproducibles

IA:
  orquesta fuentes, alternativas, matrices y continuidad
  explica decisiones para fortalecer aprendizaje humano
```

La IA no ejecuta gates. La máquina no interpreta valores. La persona no debe
depender de memoria invisible para continuar.

## 4. Unidad de avance

```text
sesión:
  ventana temporal de colaboración humano-máquina-IA

producto de sesión:
  resultado tangible o avance documentado

hito:
  logro verificable que puede requerir varias sesiones y PR

fase:
  contenedor longitudinal versionado
```
