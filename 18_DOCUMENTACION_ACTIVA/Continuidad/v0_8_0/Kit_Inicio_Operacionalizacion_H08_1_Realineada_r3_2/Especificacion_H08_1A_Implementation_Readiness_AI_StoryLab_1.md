# Especificación de H08-1A · Implementation Readiness

## Propósito

Eliminar la necesidad de inventar requisitos sustantivos durante la programación
de la primera vertical slice.

## Alcance de la vertical slice candidata

```text
perfil local sintético
→ crear proyecto
→ abrir una misión
→ guardar actividad
→ producir evidencia
→ registrar reflexión
→ decidir
→ incorporar al portafolio
→ persistir
```

## Entregables obligatorios

### Spec funcional

- actor;
- propósito;
- precondiciones;
- flujo principal;
- alternativas;
- errores;
- reversibilidad;
- privacidad.

### Interacción

- wireframes;
- teclado;
- foco;
- mensajes;
- estados vacíos;
- recuperación;
- carga cognitiva.

### Máquina de estados

- proyecto;
- misión;
- evidencia;
- decisión;
- portafolio;
- exportación cuando aplique.

### Contratos finales

- interfaces;
- errores tipados;
- schemas;
- límites;
- adaptadores.

### Aceptación

- criterios Given/When/Then;
- pruebas unitarias;
- pruebas de contrato;
- integración;
- accesibilidad;
- seguridad;
- rollback.

## Pregunta de salida

> ¿Puede una persona desarrolladora implementar el flujo sin inventar requisitos,
> resolver contradicciones silenciosamente o alterar agencia humana, privacidad,
> accesibilidad y seguridad?

La respuesta alimenta el gate, pero no lo sustituye.
