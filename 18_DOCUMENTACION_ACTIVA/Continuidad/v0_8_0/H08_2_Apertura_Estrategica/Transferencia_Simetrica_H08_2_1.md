# Transferencia simétrica de H08-2.0 a H08-2.1

## Herencia obligatoria

- datos sintéticos;
- dominio independiente;
- puertos y adaptadores;
- errores tipados;
- schemas versionados;
- agencia humana;
- reflexión privada;
- CI Node 22/24;
- auditorías;
- un único PR Draft.

## Reservas

- cerrar INV-009 e INV-010 con pruebas nominales;
- documentar persistencia mediante ADR;
- no introducir presentación antes de readiness;
- mantener legacy como oráculo, no dependencia.

## Condición

H08-2.1 comienza después del commit y push del bloque H08-2.0 en la rama
consolidada.
