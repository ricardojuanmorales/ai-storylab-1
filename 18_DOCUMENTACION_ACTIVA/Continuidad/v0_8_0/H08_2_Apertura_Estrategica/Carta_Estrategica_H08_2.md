# Carta estratégica H08-2

## Propósito

Demostrar que el baseline programable sostiene una experiencia creativa
visible, accesible, local-first y gobernada de principio a fin.

## Tesis

H08-2 construirá una sola vertical slice, pequeña pero completa. No intentará
producir la aplicación total ni absorber los hitos posteriores.

## Flujo

```text
perfil sintético
→ proyecto
→ una misión
→ actividad textual
→ evidencia
→ reflexión privada
→ decisión humana
→ portafolio reversible
→ recuperación local
→ export preview validado
```

## Resultado

Una persona podrá completar el ciclo con datos sintéticos, cerrar y reabrir la
aplicación, recuperar el estado y revisar el paquete de exportación, sin que el
dominio dependa de React, DOM o almacenamiento concreto.
