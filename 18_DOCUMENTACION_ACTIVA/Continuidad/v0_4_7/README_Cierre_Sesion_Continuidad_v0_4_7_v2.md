**Proyecto:** AI StoryLab 1

---

## 1. Propósito del paquete v2

Este comprimido sustituye conceptualmente al paquete v1 de continuidad v0.4.7.

La versión v2 ajusta el rumbo para alinear v0.4.7 con el desarrollo hacia **v1.0.0**:

```text
v0.4.7:
  Diseño de Experiencia No Funcional
  Lenguaje Situado
  Escenarios Ficticios
  Controles Habitables
```

La fase no construye experiencia funcional. Diseña su comprensión documental.

No se trata de abrir prototipo. Se trata de preparar mapas de experiencia, guías de lenguaje, escenarios ficticios y criterios de interfaz no rígida que puedan revisarse antes de cualquier construcción futura.

## 3. Diferencia principal respecto al paquete v1

El paquete v1 era seguro, pero demasiado estrecho. Enfocaba v0.4.7 como:

```text
Continuidad Documental, Lenguaje Situado y Deuda Vigilada
```

El paquete v2 la corrige como:

```text
Diseño de Experiencia No Funcional:
Lenguaje Situado, Escenarios Ficticios y Controles Habitables
```

Esto permite trabajar:

```text
[✓] mapas de experiencia conceptual;

[✓] escenarios ficticios por edad y contexto;
[✓] guías de lenguaje por perfil;
[✓] criterios de interfaz no rígida;
[✓] controles habitables;
[✓] matrices ampliadas de acciones sensibles.
```

Sin autorizar:

```text
[!] UI real;
[!] prototipo;
[!] interacción funcional;
[!] pruebas con personas;
[!] datos reales;
[!] implementación.
```

## 10. Nota de navegación

v0.4.7 debe trabajar la experiencia como un mapa de posibilidades humanas, no como una maqueta funcional.

La brújula no apunta a “construir pantalla”. Apunta a preguntar: ¿cómo se siente, se entiende, se pausa, se retira, se cuida y se revisa una experiencia antes de existir?
